# Albatastic-Scout
PCB compacta para nodos solares sencillos

-Compatible con el E22/E22P, E80, E28 y HT-RA62
-Con 2 baterías 18650 con BMS
-Posibilidad de usar 2 boosters
-Interruptor de encendido y apagado
-Incorpora un pro micro y un BME280
